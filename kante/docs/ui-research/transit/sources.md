# Transit design study — sources

All files in this folder were downloaded on 2026-11-21 and opened/inspected before being cited in `../transit.md`.
Images are third-party material kept for reference only (untrusted data; do not ship, do not copy artwork).
`.webp` originals were converted to `.png` with ffmpeg; nothing else was altered. Files in `crops/` are crops/stacks
of files in this folder, made only to view tall images at full resolution.
